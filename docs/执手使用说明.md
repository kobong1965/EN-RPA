# 执手使用说明

执手负责执行桌面操作，并把运行状态、获取的数据和可用截图交回给你。任务步骤可以由 Codex 或你的其他软件准备。执手本身不接入大模型，也不负责判断业务目标或自动设计流程。

## 开始使用

从 `执手执行器` 文件夹打开 `启动执手`。日常操作在四个页面完成：

| 页面 | 用途 |
|---|---|
| 执行中心 | 选择任务、开始或停止执行、查看获取的数据 |
| 任务库 | 导入已经准备好的任务，选择任务，调整各任务的执行设置 |
| 运行记录 | 查看各次执行的时间、状态与结果 |
| 设置 | 开关本地指令接口、复制连接配置、打开数据文件夹 |

主界面不显示运行代码。需要维护任务时，点击左下角“高级工具”，进入保留的 OculiX 工具界面。录制、截图、图像匹配设置、脚本编辑、多语言运行等原有能力从这里使用；上方“返回执行中心”回到日常操作界面。具体语言与扩展仍需要原引擎对应的运行环境。

## 运行生意参谋任务

1. 先完成千牛登录并保留有效登录状态，账号应具备生意参谋访问权限。任务从打开或恢复千牛开始，再进入工作台；不要求事先手动打开生意参谋标签页。登录失效时需先重新登录。窗口应完整显示在一块显示器内。
2. 在执行中心选择“生意参谋关键词”，点击“开始执行”。界面先显示启动反馈，再暂时最小化，由任务操作千牛界面。执行引擎初始化可能需要十余秒。
3. 运行期间保持桌面解锁，不同时拖动窗口、操作鼠标或按住修饰键。
4. 执行结束后查看状态与结果。成功返回的关键词可复制或导出；如本次保存了截图，可结合截图核对。失败时查看中文摘要，需要排查时打开诊断日志。

完整流程依次为：打开千牛 → 进入工作台 → 打开生意参谋 → 进入市场 → 打开搜索排行 → 读取关键词 → 保存结果。读取当前榜单的前 10 个关键词；任务不自动选择其他类目、日期、排序条件或后续分页，这些业务条件以页面当时的选择为准。执行时如果表格底部看不全，流程可能将目标窗口最大化。

已登录时会优先复用现有千牛会话，无需重新输入账号密码。要指定店铺，在“任务库 → 生意参谋关键词 → 执行设置”填写目标账号。内容须与千牛顶部已登录账号标签的完整名称一致，包括冒号、中文昵称等，例如 `tb账号:店铺昵称`。不要只填写缩写店铺名。目标账号不能为空；如目标账号尚未登录，先在千牛中完成登录后再运行。执行过程中不能更换目标账号。

“执行完成”表示脚本执行成功，不等同于文字已经人工核实。“待核对”结果需结合页面与截图检查。历史记录保留原来的执行时间；重新运行失败或停止时，不会把上一次的关键词显示成这一次成功采集的结果。

需要中止时，恢复执手窗口并点击“停止执行”。停止会终止本次任务及其子进程，保留已有诊断记录；不会生成一份成功结果。

## 查看进度与调整等待时间

运行期间会显示启动或执行阶段、已用时间，以及中文状态说明。执行器在后台每秒保存一次心跳；这表示执行器仍在管理任务，不代表网站已经返回新数据。任务给出明确进度时，界面会更新到对应阶段。

引擎准备与上述七个业务步骤分开显示。准备期间不会把“打开千牛”等步骤提前标记完成；每一步应在对应操作确认后再完成。旧任务缺少步骤报告时，历史结果可能显示“未报告”，这不等于执行器验证过该步骤。

所有导入任务默认最长运行 10 分钟，连续 30 秒没有新输出时显示等待提示。无输出可能只是页面加载、图片查找或其他耗时操作，不会仅因此判失败。可以继续等待，也可以停止；达到最长运行时间后，执手会结束该次执行进程，并显示“执行超时”及对应记录。

在“任务库”找到任务，点击“执行设置”，调整“最长运行时间（分钟）”与“无新进度提示（秒）”。例如，已知需要 15 分钟的任务，应提前把最长运行时间调大。设置按任务保存，影响下一次运行；运行过程中先等待结束或停止，再调整设置。

脚本明确报告错误时，执手优先显示那条具体中文原因；包装器后续的通用错误不会覆盖已识别的页面元素超时等原因。查看诊断日志仍能看到完整原始输出。

## 窗口移动与缩放

当前生意参谋流程在点击前重新获取窗口边界，使用图片模板定位目标，并复核目标外观与窗口状态。因此，在开始前移动窗口与写死屏幕坐标的做法不同，任务会尝试重新定位。

这不意味着任意尺寸、任意缩放都能执行。现有模板有有限的比例匹配候选；浏览器缩放、Windows 显示缩放、多显示器位置、网页布局变化、弹窗遮挡和主题变化都可能使模板失效。窗口太小导致内容不可见时，任务可能先最大化；找不到元素、窗口失去焦点或在校验时移动，会停止并保留记录。

以后导入的其他任务能否适应移动和缩放，取决于那个任务如何定位元素。执手不会自动把固定坐标脚本转换为自适应任务。新增网站或更换界面后，应由你的大脑软件重新演练和更新任务模板，再执行验证。

## 导入外部软件准备的任务

在“任务库”点击“导入任务”，选择 `.sikuli` 文件夹，或 `.py`、`.js`、`.rb`、`.robot` 文件。导入会登记原文件路径，不复制或改写源文件，因此不要随意移动已经登记的任务和图片资源。

外部软件可以先在本机准备任务，再把该任务登记到执手。需要展示业务结果时，由任务输出约定的结果文件；没有返回业务结果的正常任务，会显示执行完成、未提供结构化结果。接口格式与脚本输出示例见《执行器接口.md》。

准备任务的软件还可用 `OCULIX_PROGRESS <中文阶段>` 报告进度，用 `OCULIX_ERROR <中文原因>` 报告明确错误，或用结构化 `OCULIX_STEP` 事件报告具体步骤的开始、完成和失败。日常执行页面只展示这些说明与结果，无需显示脚本代码。未接入这些协议的旧任务仍使用统一的启动提示、心跳、停止与超时管理。

## 连接外部大脑软件

在“设置”启用“本地指令接口”，复制连接配置交给你允许控制本机的程序。接口每次启动默认关闭，只监听本机 `127.0.0.1`。默认端口是 `18986`，实际连接地址以复制的配置为准。

接口可以列出已登记任务、开始一个任务、停止当前任务、查询状态与历史结果。同一时间只运行一个任务。所有请求需要连接令牌，浏览器跨域请求会被拒绝。接口只执行任务库中已有的任务，不接收任意代码。详细请求示例见《执行器接口.md》。

## 文件保存在什么位置

工作区为本机 `E:\软件文件\RPA软件`。任务和结果集中保存在 `执行数据`：

- `任务.json`：已登记任务及其原始路径。
- `运行记录\每次运行编号\运行.json`：该次状态、时间、耗时及结果。
- 每次运行目录中的结果文本、原始结果与诊断日志。
- 如果本次任务明确报告了截图位置，执行器会尝试保存本次截图副本；任务未提供截图时，不保证有截图。

内置生意参谋流程的原始材料仍在 `oculix-flow\runs`。不要仅凭这个目录中“最新的一个文件夹”判断某次运行是否成功，应以对应的运行记录和状态为准。诊断日志保留原始技术信息，可能包含英文错误文字。

## 验证范围

执行后端的独立测试使用模拟子进程，覆盖中文结果、失败与历史隔离、取消及子进程终止、启动瞬间关闭、心跳落盘、无输出提示、可配置超时、中文进度、具体错误优先级、记录恢复、本次截图关联、偏好传递和接口鉴权。这些测试不操作桌面，不能代替具体网站、窗口尺寸和缩放条件下的实际流程验证。新界面的实际操作验证由交付时的运行记录说明，不把后端测试当作所有网站均已验证的依据。
